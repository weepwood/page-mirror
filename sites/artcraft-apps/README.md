## 复刻范围

目标页面是 ArtCraft 的 Crafting Apps 介绍页，包含顶部导航、主标题与简介、七个应用锚点导航、七张应用介绍卡片、Next up 区块、六条设计原则、CTA 与页脚。

## 实现

- 纯 HTML、CSS、JavaScript，无构建依赖。
- CSS 和脚本均在本目录独立维护，适配 GitHub Pages 的 `/page-mirror/sites/artcraft-apps/` 子路径。
- 应用卡片插图使用内嵌 SVG 绘制，避免依赖未确认授权的第三方图片。
- 支持应用导航锚点、平滑滚动和移动端单列布局。
- 外部链接指向 ArtCraft 官方网站、Discord 与相关开源项目。

## 已知差异 / 注意事项

目前是基于原站可访问内容和结构信息实现的首版，并非已证明的像素级 1:1 结果。卡片中的几何插图是自绘 SVG，不是原站的原始视觉素材；字体通过 Google Fonts 加载。导航、卡片尺寸、色彩、间距和动态效果需要进一步用相同视口截图校准。由于没有将原站私有资源或未经确认许可的素材复制进仓库，个别视觉细节会有差异。

请勿在未完成上述对照验收前将状态改为 `completed`。
