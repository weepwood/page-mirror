# Icon Museum Mirror

[icon.museum](https://icon.museum/) 的 1:1 静态镜像复刻版。

一个精选应用图标展示画廊，包含 228 个精心设计的 iOS/macOS 应用图标。

## 在线预览

**站点地址：** [https://icon-museum-mirror.netlify.app](https://icon-museum-mirror.netlify.app)

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/weepwood/icon-museum-mirror)

## 技术栈

- 纯静态 Vite 构建产物
- 通过 Netlify 部署，自动 SPA 路由回退
