# 已实现功能清单

这份清单按用户能力和运行环境整理当前版本，便于快速了解 Inftab 已能做什么，以及网站和 Chrome 新标签页扩展各自提供哪些能力。实现入口和开发注册方式见 [`plugin-development.md`](plugin-development.md)，端到端功能说明见 [README](../README.md)。

## 平台范围

| 能力 | 网站（Chrome、Edge） | Chrome MV3 扩展 |
| --- | --- | --- |
| 新标签页、搜索、快捷入口、工作区和内置面板 | 支持 | 支持 |
| 本地数据、设置、壁纸和 JSON 备份 | 按浏览器分别保存 | 按浏览器分别保存，可用备份迁移 |
| 天气与 Hacker News | 用户启用后联网 | 用户启用组件并点击授权后联网 |
| 书签、历史、当前标签页和常用网站 | 显示扩展专属能力说明 | 用户使用相应功能时按需申请权限 |
| 任意第三方插件代码 | 不支持 | 不支持 |

## 首页与快捷入口

- 响应式快捷入口网格，支持新建、编辑、删除、拖动排序、分页、图标上传、文件夹收纳和多工作区管理。
- 支持常驻 Dock、入口搜索与键盘操作；在 Chrome 扩展中还可从当前窗口标签页或常用网站导入安全网址。
- 支持本地时间显示、图标与网格布局调整、主题、壁纸上传、壁纸定时轮换，以及减少动态效果偏好。
- 首页小组件可固定、排序、调整宽度或移除；设置中提供“浏览发现”组件方案，一次启用天气、资讯、书签、历史和常用网站等发现类小组件。

## 搜索与内置工具

- 内置多个主流搜索引擎和网页、图片、新闻、视频、地图分类；支持添加自定义搜索引擎。
- 提供一键翻译搜索词、离线四则计算器，以及待办、习惯打卡、笔记、月历、纪念日和专注计时工具。
- 支持天气和 Hacker News 资讯。组件主动启用后才联网，显示来源；扩展还会在用户点击授权后申请对应的精确主机权限。资讯和天气会在可用时保留最近成功数据，并提供重试路径。
- 浏览器书签、历史和常用网站数据只在 Chrome 扩展提供，并由可选浏览器权限控制；撤销权限后读取的数据会清除。网站版本保留清晰说明和其余首页功能。

## 数据与恢复

- 个人设置、快捷入口、工作区、文件夹和内置工具数据保存在本机浏览器；网站与扩展使用各自的存储空间。
- JSON 备份支持导入预览、按 ID 合并或替换，并涵盖首页小组件、工作区、Dock、壁纸、习惯和计时器等设置。
- 输入和导入数据会经过类型、数量、长度和引用校验；支持跨标签页的本地变更合并，并为存储空间不足提供恢复提示。

## 内置插件接口

面板和首页小组件通过仓库内的 TypeScript 注册表接入，ID、上下文、属性与事件会经过类型检查。面板和小组件按需加载，并提供失败重试。注册表当前只执行仓库内可信模块，不加载远程插件代码，也不提供第三方插件安装与隔离运行能力。

## 质量检查

```sh
npm test
npm run check
npm run build
npm run test:e2e
npm run test:e2e:stable
npm run test:e2e:extension
```

网站浏览器流程覆盖默认 Playwright 浏览器、稳定版 Chrome 与 Edge，以及生产构建预览；扩展流程会构建 Manifest V3 包，并检查新标签页、数据保存和可选权限默认关闭。首屏 JS gzip 预算为 58 KiB，全部 JS gzip 为 130 KiB；`npm run build` 会自动核验预算和扩展包结构。

## 尚未提供

当前版本没有账号、云同步、原站通知或远程第三方插件。跨浏览器迁移可通过 JSON 备份完成。
