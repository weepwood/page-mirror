## 产品范围与实现原则

- 参考资料只采纳能可靠确认身份的产品官方页面或官方商店条目；当前已核实来源包括 WeTab、Infinity、iTab、UiTab 和 WebTab。“7070页”和“InfoTable”在确认前不作为实现依据；Dayize 按需求列为参考项，但补入其功能规格前需有可核验的官方来源。
- 网站优先验证 Chrome 与 Edge 当前稳定版；浏览器扩展按 Chrome Manifest V3 维护。关键网站与扩展工作流都应有自动化回归覆盖。
- 资讯组件已按用户主动启用、来源标注和离线恢复要求实现；未来 AI 等联网组件也应遵循这些约束，并保持搜索、快捷入口等新标签页核心功能可用。

## 当前项目对照

- 已有：多搜索引擎、快捷入口和文件夹、壁纸与主题设置、天气/待办/习惯/日历/笔记/倒计时组件、浏览器书签和历史面板、本地 JSON 备份，以及可切换的主页工作区。
- 新增：极简模式可以暂时收起组件、工作区和快捷入口，保留搜索；即使用户平时关闭搜索栏，也能直接进入可用的搜索界面，按 Escape 可返回原主页。该状态只在当前页面生效，不改动本地偏好或数据。
- 工作区支持本地创建、切换、重命名、排序和删除；默认“主页”固定在首位，快捷入口/文件夹按工作区隔离，内置工具在每个工作区保留，Dock 只展示当前工作区里的固定入口。旧版备份会迁移为单一“主页”，新版备份保存工作区及当前选择；删除工作区会将其中的自定义入口归回主页。
- 浏览器书签面板支持按搜索结果选择多个网址并一次性导入为当前工作区的快捷入口；继续使用按需书签权限，只接受安全的 HTTP(S) 地址，受快捷入口上限约束并整批成功或失败。单条添加入口保持不变。
- 首页“常用网站”组件只在 Chrome 扩展中读取浏览器提供的前五项安全网页；用户启用组件后还要点击授权，撤销权限时会清空已读取内容。网站端不会请求或读取浏览器数据。
- Chrome 扩展的快捷入口表单可按需申请 `tabs` 权限并从当前窗口导入 HTTP(S) 网页标题和网址，也可按需申请 `topSites` 权限并从浏览器常用网站列表导入；Chrome 内部页面、扩展页、凭据网址、危险协议和重复网址会被过滤。普通网站仍可手动填写，且不请求浏览器权限。
- 新增热门资讯组件：用户在设置中启用后，网站按需读取 Hacker News 官方只读 API，并标注聚合来源与文章域名；Chrome 扩展还需由用户单独授权该 API 主机。最近成功的五条资讯和更新时间会保存在本地，离线或刷新失败时保留并显示缓存，可继续重试，不影响搜索和快捷入口。
- 当前已有：仓库内受信任的面板与首页小组件注册表、类型化上下文/属性适配器、按需加载与失败重试，并在 `docs/plugin-development.md` 记录扩展步骤和质量要求。后续应在此基础上根据已核实的产品差距增加模块，并继续检查跨标签页同步、备份兼容和首屏性能。插件注册表仍只加载仓库内受信任代码，不执行远程 JavaScript。
- 插件安全边界：当前插件注册表只加载仓库内受信任代码，不执行远程 JavaScript。若以后支持第三方插件，需单独设计权限、隔离、升级和卸载机制，不应直接把远程脚本接入现有注册表。
