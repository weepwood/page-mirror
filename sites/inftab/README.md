## 复刻范围与证据

根域名的网页文本抓取目前只返回联盟披露文字和一个输入控件，主页的主要内容很可能由客户端运行时生成或依赖扩展/浏览器状态，因此无法仅凭抓取文本确认根域名的真实初始画面。官方介绍页描述了 Infinity New Tab 的快捷网站、搜索引擎切换和自定义壁纸能力；可检索到的官方/第三方展示截图也显示了渐变背景、搜索框、快捷图标和分页。

当前版本是**可交互的静态起始页初版**，并非已验证的 1:1 成品。搜索、切换搜索引擎、添加/编辑/删除快捷入口、分页、本地保存等交互为本地实现；它不会连接原服务的账号、云同步、侧边栏小组件或扩展 API。

## 已知差异与后续工作

1. 因根域名运行时画面未能直接检验，目前壁纸、布局、部分快捷入口及 SVG 图标属于依据可见展示信息制作的近似实现。
2. 搜索会跳转到所选搜索引擎的公开搜索 URL；它不等同于原扩展内置的搜索服务。
3. 当前自定义入口只保存在当前浏览器，不含登录、云备份、扩展专属功能或官方数据。
4. 页面素材许可与复用条件尚未完成全面确认；当前主背景由 CSS 渐变绘制，图标为代码绘制。

在完成同视口截图比对和关键交互检查前，请勿将状态改为 `completed`。
