## 本次修订

上一版使用了自制渐变背景、现代化顶栏和猜测的操作入口，与可查证的 Infinity 界面差异很大。本次已移除这些自创的视觉元素，按照官方展示图重新调整：

- 使用官方展示素材作为主要背景参考，并裁切掉展示图中的浏览器外框。
- 将搜索框、六个搜索引擎入口、两排圆形快捷图标和三点分页对齐到参考图的位置。
- 快捷入口改为与参考图对应的默认顺序：Infinity、Weather、Apps、History、Favorites、Steam、Google Play、Facebook、Amazon、Twitter。
- 搜索框、搜索引擎热区、快捷入口和分页均使用真实 HTML 控件，不是把整张截图直接放在页面上。
- 搜索框会把查询转到所选搜索引擎；快捷网站可直接打开。
- 加入原站可见的 eBay Partner Network 联盟披露文案。

## 已知差异

1. 官方展示图来自公开介绍页面，可能较旧；它只能作为有来源的视觉基准，不能证明与当前的动态新标签页完全相同。
2. Infinity 搜索入口的真实查询路由没有从可公开读取的页面中核实。当前实现使用目标域名的查询参数作为默认回退，其余引擎跳转到各自公开搜索地址。
3. 快捷入口当前为静态默认集合，不会读取原扩展的账号、云同步、本地浏览记录、天气、便笺、待办事项或用户自己的壁纸。
4. 远程参考图中包含原站界面的背景层；关键交互控件叠加为真实 HTML 元素。后续若取得干净的原始壁纸资源，应替换这层背景以进一步提升独立性和不同分辨率下的精度。

在拿到当前原站真实运行画面并完成同视口对照之前，状态必须保持 `building`，不能标记为 `completed`。
